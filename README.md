# Student Result Analysis with Pandas

This is my first Data Analysis project using Python and Pandas. I analyzed student result data using filtering techniques.

## What I Did
- Loaded CSV data using pd.read_csv()
- Explored data using head(), info(), and describe()
- Applied single condition filtering to find toppers and failed students
- Applied multiple conditions filtering using & (AND) and | (OR)
- Filtered students by City, Subject, Marks, and Class

## Tools Used
- Python
- Pandas
- Google Colab / Pydroid 3 (Mobile)
